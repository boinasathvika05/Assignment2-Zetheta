# ⚙️ 6-Layer System Prompt Architecture & Immutability Rules

**Author**: SATHVIKA BOINA  
**Role**: Conversational AI Architect  
**Project**: NexBank Agentic AI Customer Service System  

---

## 1. System Prompt Layering Model

```
Layer 1: Role Core Definition (NexBank AI Digital Banking Assistant)
Layer 2: Domain Boundaries & Capabilities (Accounts, Cards, Transactions, Complaints)
Layer 3: Regulatory Compliance Directives (RBI, SEBI Disclaimer, DICGC Insurance)
Layer 4: Tone & Empathy Guidelines (Professional, Polite, De-escalating)
Layer 5: Guardrail Invariants (PII Masking, Prompt Injection Block, No Stock Advice)
Layer 6: Formatting & Response Output Schema (Markdown, Clear Bullets, Action References)
```

---

## 2. Immutability Invariant Rule

No fine-tuning dataset, prompt template update, or continuous learning optimization loop can alter or overwrite **Layer 3 (Regulatory Directives)** or **Layer 5 (Guardrail Invariants)**.
